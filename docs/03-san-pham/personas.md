# Personas / Actor

| Actor | Mô tả | Mục tiêu chính khi dùng site |
|---|---|---|
| Guest | Khách vãng lai chưa đăng nhập | Xem sản phẩm, combo, bài viết; tìm kiếm; tìm hiểu trước khi đăng ký |
| User | Bất kỳ ai đã đăng nhập (tác nhân logic) | Quản lý hồ sơ, đổi mật khẩu, đăng xuất, xem thông báo |
| Customer | Người mua hàng đã đăng nhập | Tìm đúng đồ dã ngoại, mua nhanh (VNPay/COD), theo dõi/huỷ đơn, trả hàng, đánh giá, lưu yêu thích, hỏi nhân viên qua chat |
| Employee | Nhân viên vận hành | Xác nhận đơn COD, cập nhật trạng thái giao hàng, duyệt trả hàng, theo dõi và điều chỉnh tồn kho, trả lời chat hỗ trợ |
| Admin | Quản trị viên | Toàn quyền Employee + quản lý người dùng, danh mục, sản phẩm, combo, voucher, chiến dịch, bài viết; xem dashboard doanh số |
| System | Tác nhân ảo | Giữ chỗ/giải phóng tồn kho, huỷ đơn quá hạn thanh toán, xử lý IPN, đẩy thông báo, gửi email, tính gợi ý |

Chi tiết quyền hạn kỹ thuật: `docs/02-ky-thuat/authentication.md`.
